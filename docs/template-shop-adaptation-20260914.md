# 模板按目标店铺自动适配

模板不再用第一家店铺的平台和国家限制其他目标。可在同一配置中选择 Shopee / TikTok Shop 的多个东南亚店铺。店铺卡片显示实际平台、国家和币种，后端根据当前用户所属公司内的真实已授权店铺生成 `shopTargets`，并归一化 `shopIds` 和 `shopCount`。客户端伪造的目标元数据不参与保存结果。

支持现有 PH、SG、MY、TH、VN、ID 市场。最多50家，保留授权状态、组织隔离、重复选择检查。模板保存不创建发布或生成任务。旧全局 platform/market 字段保留用于兼容，旧模板读取不改历史快照；没有显式 shopIds 的历史纯规划模板可用于有效目标店铺。

批次创建、预检、店铺默认模板选择均改为按实际目标店铺校验，不再匹配首店平台/国家；有显式 shopIds 的模板仍限制在选定范围内。测试/正式环境隔离、店铺每日额度、商品版本及审批规则继续校验。现有独立商品上传流程从实际 shopId 获取平台、站点、汇率与类目能力。本次未开放 Commerce 工作流的自动刊登执行器，也未执行发布。

预算按币种分组。历史非零预算保留 `budgetCurrency`；不换汇，也不把原数字自动套入不同币种。零预算按各组保持0；非零预算不匹配的币种显示未配置。多币种的全局金额返回 null，前端按 `budgetGroups` 展示，避免误算总和。目前模板页面广告参数隐藏且默认0，不需用户为商品适配填写广告预算。

验证：53项后端测试、20项前端行为测试通过，无跳过。涵盖混平台/国家、保存与旧JSON兼容、伪造目标元数据、跨公司、授权失效、重复及数量上限、模板成员范围、批次环境隔离、默认模板下拉和分币种预算。

实际 localhost:3000 页面已将用户的「测试」保存为 v1，目标为 Shopee MY、TikTok Shop MY、TikTok Shop TH。数据库读取确认分别保存 MYR、MYR、THB，裂变数量10，广告预算0。刷新部署前，用户调整的印花另存为「圆领落肩上衣 · 直身下摆」v4，随后恢复到背面印花3预览。
