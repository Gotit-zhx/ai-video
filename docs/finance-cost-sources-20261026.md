# 分组成本文件与独立手动成本

版本：`finance-cost-sources-20261026`

## 使用

- 成本管理上方选择分组。每个分组可维护多份 Excel / CSV，支持一次选择多个文件。没有店铺的分组也可先上传成本表。
- 每份文件独立保存，可单独移除。同仓、同型号、同月份以最后导入的文件为准；移除后回退到其他仍存在的文件，没有可用价格则保持待补齐。
- SKU 关联中可选择已有 Excel 或手动成本，也可选择“手动填写成本”，输入型号、人民币单价、计价单位和每个销售单位对应的成本单位数。
- 手动资料保存在“手动管理”，可单独编辑、删除。手动固定单价适用于关联规格的历史及后续订单，修改后通过原成本队列重算。
- 所有 Excel 和手动金额都按人民币原值保存和计算，不做汇率转换。订单成本仍只在已结算口径下计入。
- SKU 关联中的 SPU 图、SKU 图及关联弹窗图片均可点击放大，关闭图片不丢失筛选和未保存表单。

## 数据边界

- V132 新增独立文件表 `finance_cost_sources` 和手动成本表 `finance_manual_costs`。`finance_cost_books` 保留为不可变的计算快照，继续支持旧订单成本追溯和导出。
- 升级前每组最新的完整成本快照迁入一个既有文件来源。若此前有多个累积版本，会明确标记为“既有合并成本资料”；不将历史累积版本伪装成可独立撤回的原文件。
- 上传文件、删除文件、增改手动成本均在分组锁和事务内完成，同时生成计算快照。手动新增与 SKU 关联原子保存，关联冲突时一并回滚。
- 同名 Excel 型号不会覆盖已经确认的独立手动单价。删除手动资料保留关联引用作为待核对状态，不自动改用同名 Excel 或其他国家的成本仓。
- 人工输入零价需明确确认；缺失单价不当成零。手动资料带版本检查，公司、分组和店铺权限沿用财务模块的管理权限。
