# 财务 BI 独立体验界面设计

用户于 2026-11-12 明确批准实施。财务 BI 完整迁移，其他模块延后。旧版继续默认使用，在旧版财务总览提供“体验新版财务 BI ↗”，以新标签页打开同源新版。新版标题显示“新版财务 BI · 正式数据”，提供返回旧版。模式仅由当前 URL 的 `financeUi=modern|legacy` 决定，不写全局偏好；不增加登录，不改 Cookie 或权限。新版提供原权限范围内的完整业务操作，正式数据和既有账户级配置共用。

## 架构

单个 `frontend/modern` Vite/React/TypeScript 工程；Ant Design、Lucide、TanStack Query、现有版本 ECharts。源码按 app/shared/features/finance/adapters 分层。财务内容挂载于 open ShadowRoot，样式、表单弹层、消息和图表由本模块管理。构建 CSS 不分包并显式插入 ShadowRoot，禁止异步 CSS 污染 document。普通旧版或非财务首访不加载现代模块。

保留 `FinanceWorkspace.allowed/canManage/enter/leave/reset` 门面。宿主适配器是唯一可读取旧会话及全局函数的地方，业务页不使用旧 `window.Finance*` 或旧 DOM。离开停止读请求、计时器及图表；退出或切换公司清理查询和订阅。API 继续 `/api/v1/finance`，JSON、二进制下载、401/403/503、异常提交分别处理。写操作无自动重放。新旧挂载互斥，失败提供旧版入口。

## 功能范围与规则

完整包含总览、实时大屏、结算、对账、订单与退款、费用与调整、成本、广告分析、财务店铺管理，以及千易、贴单、刷单、SKU/仓/国家映射、字段、导入、导出任务和授权。最新 develop 为业务基线，包含 11 月 10 日后广告来源、换算快照、成本国家仓及待补齐导出修复。后端计算、检查点、租约、限流和原始数据保持；不重新采集或启动一次性数据修复。

采用专业简洁后台、常用列优先、独立显示/导出字段、Tooltip 解释辅助信息、可见异常与处理入口、服务端分页、有效范围汇总。手机日常流程完整；360/390/768/1024/1440/1920 宽度验收，现代 Chrome/Edge/Firefox/Safari。保留七种语言与主题。金额缺失/未知/真实零分开；GMV Max 与已入账广告分开，广告佣金子集不重复相加；GIFT、千易证据、刷单汇总和利润口径保留。

## 入口和保护

旧总览按钮只出现一次，带 start/end/shopId/groupId/platform/currency/displayCurrency 白名单，过滤未知或非法参数，不传 token、授权码或私有配置。`target=_blank`、`rel=noopener noreferrer`。新旧 UI 筛选、分页、展开和草稿独立，URL seed 仅初始化一次。保持已存在字段配置的服务器作用域。新界面的提交真实生效，显式确认条件不得降级。已有 OAuth 回调地址保持，现代页可按已有接口刷新授权结果。

旧版入口和代码一直保留，只有用户明确确认后才允许切换默认及删除，不按天数或发布次数自动删除。未完成全部业务和回归前，不将体验按钮作为可用生产功能开放。

## 验收

同一受控夹具与汇率快照下，新旧筛选、汇总、明细、导出、权限及动作请求等价。包含乱序、失效会话、切换公司、未知写入结果、禁止重发、多标签页和资源清理。现有前端回归继续运行，新增现代组件和浏览器测试验证 Shadow DOM/弹层/响应式。生产验收只读，不制造真实导入、删除或重复授权。遵守用户明确要求的 Gitflow；当前源码运行方式、共享服务与维护锁按现场和适用约束处理，不能套用旧镜像状态。
