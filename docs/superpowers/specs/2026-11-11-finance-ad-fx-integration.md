# 广告资金补充、卡片去重与历史汇率口径

用户要求：按公开 API 补充广告资金数据；修复财务总览广告卡跳转后的重复卡片；统一广告文字；总览增加当前行情卡。2026-11-11 用户明确所有财务换算按订单或结算业务日期的对应历史汇率。

## 金额与展示

经营已入账广告费用继续涵盖平台账单（其中广告佣金）与普通独立广告，利润避免重复扣账单广告费。媒体投放总消耗与净消耗保留自己的来源，不能改成与已入账合计同一口径。文案分别统一为「广告费用（已入账）」「广告消耗（投放报表）」「净广告消耗」。现金、信用额度、广告费用赠款三字段统一命名。

主广告工作台只渲染一份，按币种分组卡片。多币种不相加。旧辅助大卡改为紧凑账单核对表，三张经营主表保留；跳转、刷新及晚返回不得叠加旧页。

## 公开资金来源

使用已确证的 TikTok `/bc/get/` 及 `/bc/account/cost/get/`，逐组织及实际授权去重、读取明确财务角色 BC 的账户日费用。资金源与已有 `AD` 利润、GMV 计划事实、导入来源分开存储和核对，账户总额不能复制到每家店或再叠入媒体主表。只匹配真实广告账户 ID；未知授信消耗保持未知，税额单列，不用授信余额/额度或应用积分事件替代消耗。

权限拒绝明确分类并退避，重新授权可恢复；资金接口失败不阻塞 BASIC/GMV。分页完整后发布，保留暂停、租约、旧可用数据与限流。Shopee 新 Ads 应用仍处正式审核期，不混配新旧应用密钥和令牌，不宣称当前权限已可用。

## 历史换算

- 订单/PENDING：店铺当地原下单日；退款：源退款发生日。
- 平台结算、账单、费用：既有官方结算日。
- 广告：广告账户/平台报表日；独立费用：费用发生日。
- 人民币商品及贴单成本转原币：首次结算归属日。

`fx_date` 与筛选归属日分开；跨月结算不抹掉原订单日期。逐业务日换算后汇总，不把整月合计套一个汇率。对账原币状态保持；人民币差额按各自业务日金额计算，说明可能包含汇率日期影响。

历史率固定 ECB 经 Frankfurter 的公开源，记录业务日、实际公布日及来源。周末/节假日用不晚于业务日的最近公布日；缺历史价保留未知和已知部分，完整合计/利润不能冒充已齐。不能以当前行情兜底历史金额。原业务原币事实不改写。

新增历史率与冻结快照表，保留旧参考率表及历史资料。快照可追加未覆盖日期，但已使用日率不变；同一查询、分页、下钻和导出沿用快照，导出能追溯具体汇率。当前行情另用 `/api/v1/finance/fx/market`，包含来源、报价日/时间、获取时间、`1 外币 = x CNY`、状态；行情刷新不改变历史金额或快照。

## 验收与操作

定向及完整前端回归覆盖总览跳转、重复进入、多币种、竞态、独立行情刷新；历史率覆盖两日不同价、周末、缺失/未来价、跨月订单、成本、对账和导出。真实 API 只读请求核对权限和数据覆盖，不输出凭据/原始业务响应。

V151 仅新增历史率与快照；V152 仅新增 BC 资金任务/费用存储及授权指针。隔离库验证后按共享维护锁单独应用固定摘要迁移，保留旧迁移、授权、业务卷和断点。源码只定向保存本任务文件，保留其他会话 WIP，由共享 watcher 安全点编译重载；不构建应用包或镜像。
