# Shopee 店铺广告消耗接入

2026-11-12 Ads Service 正式应用已可用并完成源码激活，店铺仍须独立官方授权，不能用测试身份或 ERP 令牌代替。现有三张主表复用 `source_key/platform/shop_id/record_date/currency/amount` 契约。

- 独立服务端 Ads 应用配置，独立一次性授权及加密店铺令牌，不覆盖 ERP 连接。只匹配同公司官方 `shop_id`，不按名称猜归属。
- 首次回补 90 天，每小时回查最近 7 天、跨天回查 31 天；按日历月分窗，每次请求最多 31 天，首次优先上个完整月，遵守官方日期格式 `dd-MM-yyyy`。窗口完整验证后才发布。拒绝缺金额、重复日期、越界日期及 warning；空响应不删除已有费用，明确 0 可更新。
- 以官方 `get_all_cpc_ads_daily_performance` 的 `expense` 为店铺 CPC 日消耗。GMS 与 CPC 的覆盖关系没有实测证据，不能叠加；页面明确这是 CPC 报表覆盖，不宣称覆盖所有广告产品。
- 新事实单独保存，只加入广告分析三表和导出，不写已入账 AD 流水、不扣利润。现金、授信、赠款、净额均保留未知；按报表业务日复用历史汇率。
- CPC 店铺日总额与相同身份的导入或旧 API 行不能双计；导入分项不按比例套到官方总额。独立表保留两份来源，展示优先官方店铺日总额并说明排除数。
- 状态与授权入口在财务店铺管理，广告分析展示配置/授权/错误及覆盖边界。只读用户无授权、暂停操作；公司切换或页面退出不应用旧异步结果。
- 新增 V154（原未应用 V153 候选改号），不改已应用迁移；数据库测试仅用可销毁 MySQL。原 9bcb 的 6 项既有 WIP 保持不变。正式环境在申请通过、独立凭据配置和店铺管理员授权前不可补出真实金额。
