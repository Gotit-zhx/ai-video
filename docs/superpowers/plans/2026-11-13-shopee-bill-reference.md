# Shopee 账单参考金额实施计划

> 按已确认口径在当前隔离工作区逐项执行，使用测试驱动与独立代码审查。用户已授权实施及统一关联显示，无需再次确认公式。

**目标：** Shopee 主金额统一为“全店 CPC 日消耗 − 已识别 GMS 同日消耗”。

**架构：** 保留现有 CPC 原始事实与检查点。新增独立 GMS 同步与日事实，通过同一 Ads 授权、令牌组租约、共享五秒间隔分阶段采集。报表在原币逐日相减后按业务日换算；未知不补零。新事实追加 DAY 失效事件；计划集合版本变化重核历史，首次口径切换用 ALL 失效事件覆盖旧分区和页面/期间缓存。

**技术：** Java 21、Spring/JDBC、MySQL 8.4、Flyway、原生前端及现代财务 DTO。

**口径：** 用户 2026-11-13 最终确认采用本次实测最接近账单的组合，而非宣称直接取得原始扣款流水。TikTok、已入账账单与利润公式不变。
