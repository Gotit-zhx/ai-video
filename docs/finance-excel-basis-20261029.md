# 财务 BI 与母婴 TK 月报口径对齐

参照用户提供的 `母婴-TK -202609月(1).xlsx`，目标为「利润表」O 列 YUXI-PH / 3PF 1，对应财务店铺 `fecf7801-0929-4076-bbaa-ee42f4dce87b`。同名 YUXI.PH / 3PF 2 是另一家店铺，分别核对。

## 统计定义

- 销售收入取 TikTok `revenue_amount`，对应源表 `Total Revenue`。商家折扣及退款冲减已含在此字段中，不再生成重复扣减的费用。
- 佣金、税费、平台物流、调整及补偿按原始字段与正负号逐项保留。销售收入减平台扣减合计等于原始净结算。无法解释的差额仍标为待核对，不能冒充具体收费。
- 原价保留为核对字段。结算明细、账单、总览、趋势、成本页及导出统一显示销售收入，原始净结算仍用于对账。
- TikTok 日期按本次验证的 Excel `Statement date` 报表日历归属：`statement_time` 的 UTC 日期加一天。这是经过逐日实数核对的报表日历约定，不是时区换算，也不表示接口提供了订单完成时间。必须有有效账单时间、已完成付款状态和付款时间，缺失时不得猜测。
- 已验证的报表日期优先于旧手工月份校正。旧校正证据迁入 `_finance_legacy_*` 字段；不再限制此类记录只能整月查询。
- Shopee 保持 `actual_payout_time` 日期规则，商品优惠与退款从原价归入销售收入，避免在费用中重复扣减。
- 成本按首次结算归属计入一次，取消行不计成本。后续退款、补偿按发生的账单日期计入收入或费用，不重复扣商品成本。成本导出明确注明「首次结算账单日期的销售收入」，后续交易应查结算明细。
- 保留现有刷单排除规则与公司共享权限。样品成本属于商品成本子项，不重复加计。

## 成本与汇率边界

本次没有将 Excel 汇总成本当作订单单价导入，也没有覆盖成本表、手工 SKU 成本或广告记录。Excel 的 PHP 月度汇率为 9.4833 PHP / RMB，系统仍使用注明来源的参考汇率。Excel 的广告分摊、退回商品成本冲回等依赖额外业务输入，不能仅凭退款状态自动假定已入库或自动补造费用。因此收入／账单日期对齐，不等于全店人民币利润无条件等于 Excel。
