# 印花人物导致误取色（2026-09-15）

第二次测试停在 EXTRACT 的颜色底图准备，而非人工套版复核。PINK/2 的图片确为粉色 T 恤；U2NetP 只保留胸前人物的灰色衣服（约 9.9% 图像），中位 RGB 为 185/181/177，引发颜色标签不一致。

本地取色服务更新为 u2netp-cloth-evidence-v2。显著性区域过小时，使用确定性 Lab 聚类寻找大面积连续布料，排除连接边界的背景、小块装饰和与印花区域分离的墙面。仅替换用于取色的 alpha；所有原 RGB 保留。没有按 SKU 名称指定颜色，不改变原图及印花。Java 继续验证 RGB 不变、区域一致性和颜色标签。

实际 PINK/2 输入通过完整 Java 调色：#EFB3BC，布色一致比例 0.89085。五项 Python 测试覆盖 RGB 保留、嵌套灰衣服图案、已有可靠遮罩和边界背景排除；CommerceGarmentColorTest 的 17 项测试通过。

已更新本地容器与持久镜像，同时更新 Java 服务协议版本及内联该版本的工作流类。第一批的已发布商品未修改。本方法仍是颜色证据，不宣称提供完整衣服几何遮罩。
