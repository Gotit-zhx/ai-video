# 入职安排与招聘 BI

二面填写意见后点击通过，先填写入职安排。姓名来自人才记录；岗位、主管、部门自动带入已有资料。确认入职日期、归属公司、固定薪资、绩效薪资、提成、导师名称与是否入职全部保存后，面试意见和入职安排在同一数据库事务中提交。取消填写保留意见，校验失败不留下部分通过结果。未入职流转到 `onboarding`，确认已入职流转到 `hired`；一面、二面已完成的历史意见仍可查看。

菜单移除投递申请与沟通记录，新增入职安排及跟进。模块按待入职、已入职、全部筛选，支持搜索、20 人分页和编辑安排。旧版二面已通过但仍停在二面的记录自动转入待完善安排，既有意见保留。资料未完善时须补齐后才能保存。

导师通知由 HR 单独点击发送。只对已确认入职的人发送，正文为“某某 已经入职，请准备好 某某 的带教计划。”通过已绑定钉钉人员或手机号核对导师身份，姓名须匹配入职表单。通知只含带教提醒，不包含薪资。保存安排、通过二面不会自动发送。发送任务幂等并保存回执；网络结果未知和服务重启后的发送中任务标记待核对，不自动重放。收件人与应用配置再次核验，发送准备期资料变更则停止发送。

招聘工作台连接卡片下展示 BI 看板，取代原快捷入口区。指标覆盖招聘需求及编制、简历审批及通过率、人才入库、面试意见及通过率、待入职和已入职、AI 寻源任务及评估人次、主动联系送达、AI 简历分析和参考分、被动邀约配置、话术及发送异常。支持时间范围、精确部门和账号/职位筛选。无法准确归属的记录列入未关联，禁止套用同名职位的不同账号记录。

日 K、周 K、月 K、季度 K、半年 K、年 K 为业务数量的周期汇总。周使用 ISO 周、周一开始；自然季度和 1–6 月/7–12 月半年周期。首末周期只统计日期筛选的部分范围。看板、周期明细、Excel 导出使用同一筛选与粒度。趋势可切换招聘需求、简历与面试、寻源与主动联系、入职、通知等指标。

Excel 导出包含统计口径、指标、部门和职位汇总、周期趋势、邀约来源、待审批账龄，以及需求、简历、储备人才、面试意见、入职安排、寻源任务及候选人、主动联系、面试资料通知、导师通知、婉拒、邀约消息、被动邀约事件、话术、部门和职位配置明细。数据使用显式文本和数字单元格，用户输入不会作为 Excel 公式执行。不导出登录凭证、钉钉密钥、候选人安全标识或私有文件地址。

统计口径显示在页面与导出文件：需求、简历、人才按创建/入库日；面试按提交意见日；寻源按任务开始日；入职安排按最后更新日。配置为当前快照。简历为份数、人才及入职为人数、跨任务寻源为人次。通过率只用已处理记录为分母；参考匹配分不替代 HR 判断；不将待核对发送计为送达。日期按北京时间处理，每次最多十年。

接口 `/api/v1/hr/onboarding`、`/recipients`、`/save`、`/identity`、`/send` 和 `/api/v1/hr/bi`、`/export` 均复用平台招聘管理员授权，写接口核对同源。导出为私有、不缓存的 XLSX。新模块直接访问服务器平台接口，统计和入职管理不依赖本机助手连接；报表不会额外调用 BOSS、钉钉或模型。
