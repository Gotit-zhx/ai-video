# 采集插件本机异常修复 v0.2.8

## 问题与证据

用户反馈“插件暂时无法完成操作”，部分用户换电脑后恢复。旧版后台把未分类的 JavaScript 异常统一替换成这个文案，因此单靠提示无法判断具体原因。

使用官网下载的 v0.2.7 运行本机环境回归，模拟电脑时间比平台快 12 小时、平台返回仍有效的 8 小时凭证：旧 `writeAuth()` 抛出“平台返回的访问凭证已经过期”，最终被转换成用户看到的笼统错误。这证明旧版本存在与本机环境相关的故障，但尚未取得受影响用户电脑的诊断，不能认定每例都是系统时间问题。

## 修改

- 使用平台 HTTP Date 计算时差，校验登录、展示登录状态和清理待撤销凭证时使用同一时间基准；保留平台原始到期时间，服务端 401 仍清除登录。
- 兼容旧权限缓存的非数组值，防止个人浏览器配置引发类型异常。
- 工具栏徽标更新失败不再把成功登录或已保存采集误报为失败。
- 明确识别成功状态下的无效 JSON；网络或代理异常保留有效登录；保留正常的 204 退出响应。
- 本机存储、浏览器兼容性和其他异常分别显示具体提示或阶段编号；不向页面返回原始异常中的凭证，也不新增持久日志。
- 插件窗口显示当前版本、时间校正提示和“检测本机连接”。
