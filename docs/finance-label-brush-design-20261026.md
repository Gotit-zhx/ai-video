# 财务订单标签与贴单费用（2026-10-26）

按用户最终确认的简化口径实现：导入文件自动匹配原订单，显示黄色“刷单”标签，经营汇总排除对应订单及其结算、关联平台费用、商品成本和贴单成本。原平台订单、退款、结算、费用与账单不改写；平台原始对账继续包含完整流水。此功能仅用于内部统计，不执行下单、退款或平台操作。

## 费用入口

“费用与调整”保留平台费用；另一入口为“贴单成本与刷单成本”，含三个分类：

- 贴单成本：按分组、国家、生效日期维护人民币每单价格；国家规则优先于分组默认，按下单日期选择规则。已发货订单只计一次，首次结算进入经营成本；未发货不计。已有独立订单成本记录时标为待核对，避免重复加计。
- 刷单成本：按分组导入 Excel / CSV，预览后确认；显示文件、匹配订单、未匹配来源和去重人民币服务费。服务费单独统计，不混入正常经营利润。
- 历史其他费用：保留旧费用台账及调整记录。

无需增加人民币返款或商品出库确认步骤，不把原币本金转换或混入人民币服务费。本金仅用于核对平台订单身份与金额。

## 识别与撤销

以公司、分组、精确订单号、店铺名称、原币金额唯一匹配，绝不使用买家账号作为店铺标识。首次匹配后保存店铺唯一 ID，店铺改名或调整分组不丢标签。尚未同步的订单在后续平台同步时重新匹配。

同文件摘要去重；同订单多文件只有一个标签和一份服务费。不同来源服务费冲突时标记待核对，不直接相加。移除文件只撤销该来源，最后一个来源移除后恢复经营汇总；商品成本资料和原始成本快照不变。店铺删除同步清理标签与已关联的导入行，其他店铺及共享文件不受影响。

原始财务导出提供“订单标记”“经营汇总口径”字段，默认包含，已有自定义导出字段仍尊重用户配置。成本导出只列经营汇总范围内的订单，贴单费仅在订单层计一次，不复制到每条 SKU。

## 数据与性能

V133 新增贴单规则、费用来源文件、来源行、订单标签四张表，并在已有成本快照增加贴单价和待核对状态。所有来源更改有审计，写入受公司角色管理权限、同源请求和事务保护。

汇总仍使用原覆盖索引扫描，通过订单标签和订单关联索引查询少量需要排除的记录，在后台扣除对应统计桶；避免为了少量标签读取全部订单 JSON。成本汇总通过索引排除标签；结算日期、店铺、国家、分组和币种筛选继续沿用原口径。
