# 通用生成素材引用与视频参考

已部署：输入 @ 可筛选并选择上传素材，插入 @图片1、@视频1。支持键盘选择、图片删除后的编号同步、视频预览与移除。图片最多 9 张，视频最多 1 条，支持视频单独作为参考；素材合计最多 90 MB。视频为 MP4、MOV、WebM，带视频使用质量线路。

后端校验数量、引用编号、视频容器与真实视频流。视频保存在独立 VIDEO_REFERENCE_VIDEO 资产中，提交时保持 video_url/video MIME，不进入图片转 JPEG 流程。模型提示中注明素材编号与请求顺序的关系；已有任务结果视频与参考视频分别展示。

验证：33 项后端测试通过；真实文件在生产相同 Java/ffprobe 环境验证纯视频、混合素材保存，以及第二条视频和伪造文件拒绝。浏览器使用隔离页面复用实际界面代码，验证上传、@选择、引用重排、视频单独提交，提交 API 为测试替身。大衍载荷以本地 HTTP 服务验证，未发起付费生成。生产文件哈希、HTTP 静态文件及应用健康检查通过。
