# 采集商品尺码模板修复

原发布模板只保存详情文案、包裹重量和长宽高，没有服装尺码图字段。
Shopee 发布器也没有读取模板尺码图的路径，因此原图识别失败会中止商品提交。

- 定制模板新增“通用尺码表”，支持上传、预览和移除 PNG/JPG 图片。
- 图片按公司归档；保存时再次校验归属，发布只读取该公司的归档内容。
- 启用模板并配置尺码图后，直接向 Shopee 上传已选尺码图，填入
  `size_chart_info.size_chart`，不调用原图 OCR。
- 未配置模板时保留原图识别路径；文字尺码提取改为优先读取保留的
  `normalized_data.originalDescription`，避免通用营销文案覆盖原尺寸数据。
- V111 仅新增可空图片引用列，不修改已有模板和发布记录。

验证：56 项相关 Java 测试与 4 项前端测试通过；线上模板弹窗已核实显示新入口，
旧的详情文案和包裹参数保持不变。

本次核对到 6 件未删除商品、12 个因尺码表中断的任务：
BARE PH 与 CORA PH 各 6 个；均未进入商品创建，没有目标店铺成功回执。
原任务和店铺关系已保留。当前两个店铺的官方尺码模板列表均为空，
平台模板也没有实际尺码图，所以尚未重新提交这些任务。
需要业务方提供适用于这些商品的尺码图后才能使用模板续传，
不能把包裹尺寸当作服装尺码，或补写未经提供的尺寸。
