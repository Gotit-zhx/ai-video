# 财务已结算订单成本与详细 Excel 导出

财务页面此前按所选下单日期汇总商品成本，会把尚未结算的订单成本与当期平台结算净额放在一起。现在各模块统一使用平台已结算订单的商品成本，并显式标注统计口径。

## 统计规则

- 以官方接口记录中的 `SETTLEMENT / API / SETTLED` 确认订单已结算。
- 总览、店铺和分组汇总、实时大屏及默认订单成本查询，按首次平台结算日期归属成本。相同公司、店铺、订单只认列一次整单商品成本。
- 结算明细、结算账单和对账中心仅归集首次结算对应的成本。同一天存在多条结算时，以稳定的记录顺序选一条承载成本；后续结算调整不重复认列整单成本。
- 未结算订单显示“未结算，不计入”；未新增成本的结算记录显示“本条未新增商品成本”。待结算页面不统计已认列商品成本。
- 退款页仅核对退款关联的已结算订单，订单去重，不把退款关联成本再次扣减或自动冲回。
- 单笔记录下钻以所选记录为准，不使用下单日期排除相关已结算订单。
- 金额仍取人民币商品成本表，结合店铺成本仓、商家 SKU、数量、组合数量和价格月份。平台结算不代表银行到账，标准商品成本不等于仓库实际出库成本。
- 缺订单、缺价、缺型号或后台重算中的订单保留“待补齐”；完整成本留空，已计算部分单列。历史月份取价继续标为估算，重算中的旧成本不进入报表。

人民币成本不参与平台原币换算。订单、广告、平台费用和账单金额本身仍沿用各自业务日期与原币口径。Redis 财务快照命名空间已升级，避免发布后读到旧的全订单成本。

## Excel 导出

入口：**财务 BI → 成本管理 → 订单成本 → 导出 Excel**。

导出当前店铺、分组、平台、币种、日期或单笔来源记录范围内的全部相关订单，不受页面分页限制，包含：

1. **汇总说明**：筛选条件、日期依据、统计口径、订单和 SKU 行数、完整与已算成本、缺失和估算说明。
2. **订单成本**：平台、店铺、国家、分组、订单编号、商家 SKU、下单日期和时分秒、首次结算日期、原币金额、人民币成本、成本仓、目标和实际取价月份、状态及来源文件。
3. **SKU 成本明细**：商品和规格、平台 SPU/SKU、商家 SKU、成本型号、购买数量、组合数量、单价、商品行成本、价格月份、缺失原因及快照版本。

导出使用只读、可重复读事务和已保存的计算快照，每页读取 500 笔；最多并发 2 个导出、50,000 笔订单、200,000 行 SKU。超过上限明确提示缩小范围，不静默截断。临时文件在完成或异常后清理。订单编号按文本保存，金额和日期按 Excel 对应类型保存；来源文字不作为公式执行。仅白名单商品字段进入报表，不导出买家联系方式。
