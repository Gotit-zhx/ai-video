## 行为

- 订单成本表的“商品 SKU”右侧新增“平台 SPU”，同单多个商品 ID 去重分行，长编号保持文本精度。
- 当前公司、分组和成本仓内自动匹配：商品 SKU（含原有格式规范化、组合装规则）→ 平台 SPU → 人工确认。平台规格 SKU ID 不作为 SPU 使用。
- 保留人工确认、独立手动价格、GIFT、取消订单及实际履约成本优先级；已命中型号的缺价、零价、数量问题不通过切换 SPU 价格掩盖。
- 前端关联提示、自动关联接口和订单计算共用相同顺序；已有自动 SPU 关系遇到新的有效 SKU 型号时重新优先 SKU。大成本目录按仓构建并复用查找索引。
- 更新计算源哈希版本，使后续同步及现有重算入口能更新旧算法结果；本次没有全历史入队、数据库迁移或原始账本写入。
