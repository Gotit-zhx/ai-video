## 现场原因

官方 `get_all_cpc_ads_daily_performance` 提供店铺每日 `date`、`expense`，但文档允许的应用类型不包含现用 ERP System。此前 ERP 真实读取为 403 / `error_api_permission`，本轮未更改原应用配置或店铺令牌。

本轮两次在默认 Edge 查看新 Ads Service 应用，正式状态仍为 `Application to go live is under review`、`Developing`，尚无正式 Partner 身份。申请已接收不等于可调用正式 Ads API；新应用必须使用自己的正式凭据与店铺授权，不能套用原 ERP token。实现前原代码也没有 Shopee Ads 日报采集入口，因此仅等待审核并不能自动填入旧页面。

## 实现范围

- `FinanceShopeeAdsSettings` 读取 Git 外独立私有文件；未配置或 `live-enabled=false` 时不请求上游。不读取原 ERP Secret。
- 独立一次性 OAuth 会话校验公司、应用 revision、有效期及消费状态。`FinanceShopeeAds` 单独加密店铺凭据，并按官方 `shop_id` 匹配同公司唯一财务店铺。
- 每次读取最多七日 CPC 日报；原始 JSON 数值使用签名客户端精确十进制入口。首次近 90 天、每小时近 7 天、每日近 31 天回查，共享至少五秒请求间隔和限流退避。
- V153 新增授权、无凭据的组租约及独立店铺日事实。组租约保护共享刷新；暂停/删除不造成兄弟令牌遗失，也不恢复已删除密文。瞬时数据库失败仅重试保存已取得的令牌，不重复刷新 POST。
- 空刷新、warning、缺金额或日期不完整保留旧事实；明确 0 可以更新。同店铺同日总额不因导入或重新授权重复累计。
- `FinanceAdSpendService/Report` 将来源接入分组、店铺、明细及导出，复用按业务日的历史汇率。无资金分项不补零、不从合计倒算。GMS/CPC 覆盖关系未取得真实证据，不相加、不宣称全广告产品完整。
- 不写原已入账 `AD` 事实，不调整利润。新 UI 显示配置、授权与异常原因；只读用户无写按钮，退出/公司切换使旧授权回复失效。现有账户和真实业务原件未上传到新应用。
