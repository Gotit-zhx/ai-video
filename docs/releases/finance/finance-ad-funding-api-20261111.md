## 原因与字段映射

此前 `FinanceAdSpendReport.api` 将现金、授信和赠款全部固定为空；GMV Max 同步虽已请求并保存 `metrics.net_cost`，主表却只读取 `cost`。普通 BASIC 请求亦没有包含官方账户资金指标。

- GMV Max：`cost` 对应总消耗，`net_cost` 对应剔除广告赠款和优惠券后的净消耗，支持现有计划/日粒度；净消耗不能改称现金付款。
- BASIC：新增请求 `billed_cost`、`cash_spend`、`voucher_spend`。其中净消耗可以展示；现金、赠券仅在账户日报粒度读取，不复制到 GMV 计划和多店金额。
- `ad credit` 指广告优惠，`spend_credits` 指应用内积分花费的转化事件，均不能充作信用额度消耗；未取得真实授信消耗分项时继续未知。
- Shopee CPC/GMS 的 `expense` 是广告消耗，所核对报表没有现金、授信、赠款和排除优惠后的净消耗分项。现有权限问题没有通过填零或字段别名绕过。

三表及导出增加「净消耗（剔除赠款）」，保留原币和同一参考汇率转换。接口未拆分、接口未返回和报表未提供分别说明。账户资金在折叠核对区单独保留，即使账户总额被系列去重排除也不丢失已取得分项；其金额不进入店铺合计。人工分配不复制整条 API 净消耗，原资金指纹和利润流水保持原规则。

补查 v2.0 正式指标页仍将现金、赠券限制于账户级；与该版本同步接口的系列级示例存在不一致，未以示例扩大粒度。旧 GMV Max 报表类型亦列为弃用，不能据普通报表示例替代当前专属接口。此补查不改变已生效源码及金额。

官方字段、延迟及来源链接见[广告业务说明](../../business/finance/advertising.md#api-资金指标与净消耗)。
