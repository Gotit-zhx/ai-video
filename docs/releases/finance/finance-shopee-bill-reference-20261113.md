# Shopee 广告账单参考金额（2026-11-13）

用户最终确认采用本轮实测最接近财务账单的组合：全店 CPC 日报消耗减去已识别 GMS 同日费用。主标签为“广告消耗（投放 / 账单参考）”；这是参考口径，不是原始扣款流水，也不承诺与账单逐分一致。

## 实现与边界

- 原始 `finance_shopee_ad_daily`、ERP 授权、CPC 检查点、已入账费用和利润公式保持原义。V158 独立保存 GMS 同步及日事实，复用 Ads 令牌组租约和五秒共享间隔。
- GMS POST 报表只发现计划 ID；扣除值取产品计划 GET 日报的完整计划全集、店铺、日期及同币种金额。明确零和负数保留；缺日、权限、warning 和缺金额均不补零。
- 已识别计划集合版本化；发现新计划后旧版本日事实暂时未知并重核历史。超过 100 个计划也先使旧版本失效，再明确拒绝不完整采集。
- 所有主表和导出共用同一入口，在原币逐日相减后换算历史汇率。“全店 CPC 原额”和“已扣除 GMS”只辅助核对。旧投影缺字段、仅有旧 API/导入时主金额待补齐，不回退全店原额或其他来源；其他来源原额以 `source_reported_amount` 原币保留。
- 首次 ALL 事件覆盖拥有 Shopee 授权、旧 API 或导入的公司；后续日事实和范围变化发 DAY 事件，按现有投影 revision 刷新页面与期间缓存。
