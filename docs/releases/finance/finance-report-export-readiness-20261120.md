# 财务报表数据就绪与导出任务

2026-11-20 在独立开发分支新增统一导出入口。默认财务工作台覆盖通用报表、结算及对账、广告三张表、平台费用汇总、订单成本与千易售后。仍复用现有报表字段、币种、日期口径和下载鉴权。订单成本继续使用原有 Excel 分片及 ZIP 能力。

- 页面区分「处理中」「部分待补齐」「处理异常」「可导出」。状态由服务端根据报表和筛选范围重新核对。近期刷新只在检查点与所选日期相交时影响相应来源。缺少日期覆盖或原始金额时保留缺口。
- 处理完成提醒是账号内通知，后台按有界队列检查。提醒持久化，保留 7 天。文件任务保留 30 分钟，应用重启后需重新生成。重复提交使用幂等键。
- 服务端校验提交版本。未就绪任务无法按正式报表生成。部分范围的 Excel 带数据状态工作表及文件名标记。生成时捕获的条件和汇率证据会用于本次报表。
- 对账、普通记录、费用、广告、千易和成本的历史文件接口继续兼容现有调用。默认工作台使用新的任务和提醒接口。

## 接口

| 方法 | 入口 | 用途 |
| --- | --- | --- |
| POST | /api/v1/finance/report-exports/status | 核对当前报表和筛选 |
| POST | /api/v1/finance/report-exports | 校验版本并提交后台生成 |
| GET | /api/v1/finance/report-exports | 读取当前账号的提醒和任务 |
| GET | /api/v1/finance/report-exports/{id}/download | 下载已经生成的文件 |
| POST | /api/v1/finance/report-exports/reminders | 订阅当前筛选 |
| GET | /api/v1/finance/report-exports/reminders/{id} | 读取已就绪提醒的筛选 |
| POST | /api/v1/finance/report-exports/reminders/{id}/dismiss | 关闭或取消提醒 |

共享服务器上线依赖新增 Flyway 迁移 `V167__finance_report_export_reminders.sql`。生产迁移按共享服务器运维流程单独执行。独立试用版前端位于另一功能分支，本次未在该预览入口验收。
