# 成本管理与费用台账

> 历史发布记录；镜像、测试与“当前/最新”均指记录当时。 当前入口见[业务说明](../../business/README.md)与[运维指南](../../guides/operations.md)。

用户确认设计后，将「成本管理」和新版「费用与调整」接入正式服务。

- 成本文件支持仓库/型号/月度横排及四列长表。辅助公式列忽略；用于成本的字段含公式时拒绝导入，不读取不可信公式缓存。相同文件去重，新版本合并历史月份并保留原版本。
- 商品规格从已有订单投影，最多读取最近 2,000 笔订单，保留店铺、商品 ID、规格 SKU ID、商家 SKU 与销售规格，不返回买家原始信息。全量平台商品目录同步未启用。
- SKU 映射和成本口径写入公司共享数据；保存校验仓库/分组，并以版本避免覆盖其他成员的修改。规格冲突需人工确认。
- 费用台账有独立日期、分组、币种和分页。订单归属查验、重复来源编号保护和费用调整审计在服务端执行。金额使用 DECIMAL；前端提交原始十进制文本。
- 单独计入的店铺/订单费用以事务写入 BI 外部成本；改为「已含」会移除该手工费用对应的重复计入，保留完整调整记录。平台原始记录不变。
- 分组公共费用待分摊，分摊规则可保存但不自动执行。自动订单成本/利润计算仍为预留，需要先确认币种、单位与成本组成。
- 保留原平台费用、旧导入、字段设置与导出入口。角色权限沿用 `finance:view` / `finance:manage`。

验证包括独立 MySQL 数据库集成测试、实际提供工作簿的本地解析、财务权限与来源验证、前端保存/刷新/只读角色测试，以及店铺和对账回归测试。

发布使用 V127 新增六张表，不修改既有账单。以生产实际镜像为基础，仅替换四个财务类族及相关静态文件；旧镜像留作回滚。同步任务在请求完成后短暂排空，保留游标并恢复原计划。

2026-10-22 已部署正式环境，发布标识 `finance-cost-workspace-20261022`。V127 和六张表检查通过，静态文件及 gzip 内容均与发布清单一致，未登录访问财务接口仍返回 401。应用、前端配置及无关服务保持原样，原财务同步计划已恢复。

最终后端相关验证共 48 项通过（包括两项独立 MySQL 集成测试）；成本预览、真实接口模式、店铺分组和对账前端回归均通过。用户提供的母婴成本表已初始化至母婴组，共 126 条成本资料、12 个月份；币种、单位与成本组成待确认，未自动建立 SKU 映射或生成费用、利润。
