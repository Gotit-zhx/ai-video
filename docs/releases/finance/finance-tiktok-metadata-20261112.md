# TikTok 广告字段补齐：首次验证与后续状态

首次记录日期：2026-11-12（Asia/Shanghai）。分支 `feature/finance-tiktok-funding-fields`，从 `develop` 的 `5133612` 建立。当日交付为本地代码及草稿审查，当时共享服务器未写入、未执行 V156；后续生效结果见下方 11 月 13 日更新。

后续更新：V155/V156 联合验证及源码生效已于 2026-11-13 完成，见[源码生效回执](finance-tiktok-metadata-20261113.md)。下方首次测试记录保留 11 月 12 日边界；商家重授及真实资金完整性仍待验收。

## 本次实现

- GMV Max 详情、普通系列及广告组元信息按真实账户/系列 ID 异步补齐。普通及删除列表均未返回时尝试专用 GMV Max 详情；不按名称猜测身份。
- 三张广告主表保留。店铺消耗明细增加官方目标店铺、推广目标及资料状态；来源详情与 Excel 导出保留相同资料来源、时间、状态和目标 ID。
- 当前推广目标仅为关系证据，标明 `historical_allocation_verified=false`，不改历史店铺归属、金额、指纹、原始流水或利润。预算、余额、发票总额不替代现金/授信/赠款消耗。
- 暂停/恢复、重授和删除撤销旧任务租约；请求前后核对当前账户/凭据。过时调度不能绕过下一次执行时间。平台或网络失败保留分页；页数缩小、重复/变更分页重新查询，保留原成功资料。
- V156 新增独立派生资料和任务表，内容/错误状态变化为受影响的财务日期追加精简 `DAY` 事件；同内容定期复核不重复触发内容事件。

## 后续集成与验收状态

1. **V155 联合验证已于 2026-11-13 完成。** 常规夹具使用真实 V150/V155/V156；日期事件、期间修订及 Redis 页面键最终 64/16/13 项回归通过。共享服务器已从真实 V155 显式追加 V156，结果见[11 月 13 日验收](finance-tiktok-metadata-20261113.md)。
2. **商家授权尚待更新。** 应用新权限已获批，但本轮原有令牌对 `/campaign/get/` 和 `/adgroup/get/` 的只读实测仍返回 `40001`；用户明确选择稍后重授。新授权后的真实字段、全部账户及历史系列覆盖尚未验收。
3. **三项资金未宣称补齐。** 本轮尚未取得官方发票文件的完整字段契约，未接入未核实的资金文件。原表九列、系列/日/币种的现金/授信/赠款及跨店实际资金归属仍需取得正式字段依据并实测对账；不填零、不倒算、不按比例猜分。官方确认工单为 `4552134`。
4. **正式链路仍需复测。** 通过现有服务器广告代理的独立 HTTPS 探测出现 TLS 失败；本轮未修改网络、代理、凭据或路由，也未据此宣称生产广告应用已完成端到端验证。
5. **共享窗口已串行完成生效。** 2026-11-13 保留同期性能、成本和 Shopee 源码，完成 V156、原数据摘要与实际页面验收后释放窗口。新版 React 发布继续按独立审查及串行交接处理，新增响应键均可选。

更新授权后元信息任务会自动唤醒，沿用已连接账户、现有资金原值及已核实分配；不要求重传完整资金报表。常驻规则见[广告分析](../../business/finance/advertising.md#tiktok-系列资料与目标店铺补齐)。
