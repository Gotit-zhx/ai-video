# 招聘模块数据可视化

> 历史发布记录；镜像、测试与“当前/最新”均指记录当时。 当前入口见[业务说明](../../business/README.md)与[运维指南](../../guides/operations.md)。

## 页面行为

- 招聘工作台显示连接状态；已验证账号不再显示扫码引导和凭据诊断 JSON。
- 职位显示名称、薪资、地点及可展开的说明，可以直接进入对应职位的推荐、投递和沟通。
- 人才和投递显示候选人卡片，适配实际 `geekList[].geekCard` 与 `result[]` 返回结构。
  仅展示平台提供的经验、学历、期望城市、最近经历、技能和活跃状态，不虚构资料或评分。
- 职位筛选使用下拉框；候选人简历和会话入口自动携带必要标识，不要求用户手填 ID。
- 沟通使用会话列表和消息气泡，支持文字、简历卡片、附件提示、时间顺序与发送方区分。
- 在线简历按基本信息、工作、项目、教育和证书分区；缺少平台要求的安全标识时不展示失效入口。
- 简历索取仍需用户点击并确认，查看页面和测试不会发送招呼或请求。
- 移除用户截图红框中的整个横幅：英文标识、标题、宣传文字和“刷新当前数据”按钮。

列表不再仅保留前 30 条；分页按平台 `hasMore` 等信息控制。筛选职位的读取与候选人
查询顺序执行，避免竞争同一账号连接器。切换页面、退出或切换公司后，旧请求不能覆盖新页面。
上游文字使用 `textContent` 渲染，不执行返回内容中的 HTML。
