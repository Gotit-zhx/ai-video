# 成本表与店铺商品关联简化

- 成本管理只保留成本表、SKU 关联，设置入口保留成本仓与计价单位。订单成本、利润、分摊等预留界面移除。
- 平台费用恢复为「费用与调整」默认页面，日期筛选、字段、导入和导出保留；其他费用单独切换。
- 成本表金额统一按人民币记录，不进行汇率换算。首次进入优先选择已导入成本表的店铺，店铺外层显示成本资料数量。
- 关联按店铺、平台 SPU、平台 SKU 分层。商品层汇总绿色已关联、红色未关联、橙色需核对数量，异常项优先展示。
- 相同商家编码自动保存成本型号关系，覆盖成本表中该型号的各仓库，不猜测实际仓库、单位换算或利润。已有人工关联不覆盖，重复执行不新增记录，不跨店写入。

后端使用独立 MySQL 测试默认店铺选择、人民币标识、自动关联幂等、人工关系保留和公司隔离；前端测试 SPU 分组、颜色文字、权限、店铺切换失败保留原视图以及平台费用恢复。发布仅覆盖两个财务类及相关静态文件，保留 V127 和既有结算、费用、同步进度。

已发布 `finance-cost-shops-20261022`。正式应用类的实际数据校验确认：母婴店 126 条成本资料、12 个 SPU、52 个 SKU，30 个 SKU 自动关联至 82 条对应仓库关系。原成本文件已记录 CNY，原始数值不变；实际使用仓库与单位换算未猜测，未生成订单成本。正式默认页面能选中已有成本资料的店铺。
