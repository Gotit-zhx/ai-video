保留原默认驱动线路。当前公司其他启用的 DRIVER 配置作为备用（最多两条），按更新时间排序；生图的版权备用配置不受影响。备用配置使用独立加密密钥。此次将当前生图地址复制为 grok-4.6 驱动备用配置，不改动 OSS、默认驱动或生图线路。

商品分析、首帧校验、watch 视频拆解、人工脚本、旁白翻译及助手/自动化驱动请求携带备用连接。主线路认证/访问失败、限流、模型不可用、网络或服务故障可切换。总调用时间有上限，每条最多执行一次线路尝试（原有明确参数兼容协商仍保留）；已向调用方输出正文、外部取消、内容过滤、错误参数或非法工具调用时不切换，避免拼接不同模型的内容或重复执行工具。不会自动重启已暂停的历史生成任务。

脚本详情可删除选中分镜，至少保留一个。删除及重新编号、按剩余原时长比例分配总时长、重建 JSON 在同一事务内完成。保存原视频时间点与预览编号，后续删除不改变对应真实画面。既有生成任务快照不重写。

参考图渲染仍采用九格。对于删减脚本，新任务将保留的最长场景分段为连续参考格，不恢复被删内容，不重复旁白；脚本管理显示实际剩余分镜数量。至少保留一镜，生成仍需遵守原有时长/资料约束。
