# 模板配色、可选主图风格与印花缩略图

> 历史发布记录；镜像、测试与“当前/最新”均指记录当时。 当前入口见[业务说明](../../business/README.md)与[运维指南](../../guides/operations.md)。

模板配置增加可选的主图风格和显式配色。颜色支持色盘、常用色和 HEX 输入，并随印花模板版本保存。选中风格后，发布图集全部由所选主图模板提供；生成未完成时不能混入旧商品主图。未选风格保留原图集流程。首页和原有主题样式不变。

新模板配色通过已保存的模板在服务端冻结，不能由提交计划的客户端覆盖。前后左右的服装改色使用配置色号；原商品仅提供尺码、售价、库存等规格。新颜色生成独立的 SKU 标识，规格冲突仍要求核对，不能叠加原商品库存。

已存在且没有配色字段的不可变模板保持旧行为。编辑保存新版本需配置至少一种颜色；历史执行继续使用既有快照。

印花裂变改为必须大幅重新创作主体、构图和元素关系，不以换色、换表情、镜像或微调配件充当新款。每组的 20 款使用不同的主体与构图组合，修复此前每 3 款重复同一方向的问题；不同图案组错开方向。保留画风与透明 PNG 要求，提取原印花仍忠实还原，套版阶段仍固定已生成的新印花。已归档或已固定请求继续复用，新增方向仅用于新任务。差异目标属于生成指令，不宣称已通过真实模型的视觉差异验收。

印花列表和选择后的缩略预览使用最长边 256 像素的透明 PNG，按需加载，不再向浏览器传输高清原图。服务器按公司与内容指纹缓存最多 128 张小图；每次请求仍校验当前素材归属与权限，浏览器私有缓存需重新验证。首次访问的历史素材需读取原档生成缩略图；后续命中缓存。实际制作与“查看透明原图”保持使用原始高清文件。

## 视频生图与自然表情

模特母版提示词升级为 REALISM V7，移除默认 2–10 度侧倾、强制肩髋高低差和仅允许嘴角变化的要求。头颈默认舒适中立，允许轻微转脸；表情由眉眼、面颊和放松的闭口嘴角共同呈现，不固定为同一种笑容。采光、面料、商品结构和人物身份要求保持。

九宫格不复制母版偶然的歪头或固定表情。视频默认提示词升级为 DIRECT_DETAIL_V7 / V11.9，允许自然眨眼、动作目标对应的视线变化和轻微闭口表情起伏；不按固定节奏反复挑眉、挤眼或摆头。脚本明确的转头、低头、抬头和侧倾仍按动作执行，背身和遮脸不补脸、不强制转正。最终提交的音画规则同步澄清“闭口不等于表情冻结”，继续禁止人物说话或对口型。

原有系统生成的视频提示词沿用已有机制升级，未带系统版本标识的自定义提示词不重写。提示词升级不触发付费生成或废弃现有资产；已生成的图片保持原样，新生图或用户明确重做才使用新图像提示词。

## 验证

- 261 项相关商品后端测试通过，覆盖配色校验、计划冻结、原生透明印花、裂变方向、四面改色、SKU 规格、风格图集和缩略图权限/缓存/原图保真。
- 114 项视频相关测试通过，覆盖头颈、自然表情、旁白与面部动作兼容、静默约束、旧提示词升级、自定义文本保留、已有图片复用与重新生成流程。
- 60 项相关前端测试通过；修改的 JavaScript 语法检查通过。
- 本地隔离页面使用真实前端代码和模拟 API，验证风格与颜色保存/刷新回读、清空可选风格、三位 HEX 归一化、重复与非法色号拦截。
- 390 像素视口无横向溢出，色盘保持在可视区域；素材选择加载 6 张 256 像素缩略图，原图请求数为 0。
- 修复实际浏览器验收发现的固定画布遮挡和色相条被全局输入框背景覆盖的问题。
- 原测试中的二维印花样本在未修改的基线也会失败，已仅修正为原生透明 PNG 样本，生产透明性检查未放宽。
- 发布前核对受影响的 91 个既有生产类，均与基线源码规范化字节码相符。

验证没有创建真实付费图片或视频任务，也没有向店铺发布测试商品；本次尚未用新生成样本验收印花差异或头颈与表情的实际视觉效果。

## 发布范围

使用 `scripts/release/release-template-palette.py` 在当时运行的应用和前端镜像上覆盖本次类与静态文件。保留其余 JAR 条目及环境、挂载、网络配置，不改数据库结构，不更换 Pi/招聘服务。HTML 保留线上 HR 脚本原有缓存标识。

发布流程校验当前镜像基线、任务空闲、视频提交/审核/轮询租约、健康状态及 HTTPS 静态文件指纹；失败回退到发布前镜像。已被提供方接受的视频任务保持可恢复。验证后清理重复构建文件，保留回滚镜像与发布凭据。
