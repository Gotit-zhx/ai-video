# Shopee / TikTok Shop 双向搬运（2026-09-10）

> 历史发布记录；镜像、测试与“当前/最新”均指记录当时。 当前入口见[业务说明](../../business/README.md)与[运维指南](../../guides/operations.md)。

已部署本地 app 与 frontend，健康检查 UP。以已采集商品为来源，发布路由由目标店铺决定。

- 批量店铺选择同时包含 Shopee 和 TikTok Shop，按目标平台读取配置、保存偏好和提交任务。
- TikTok 类目/仓库通过授权店铺 API 读取，先校验公司归属，90 秒整体截止时间与中断取消沿用现有实现。
- 跨平台类目按完整路径或唯一叶子名称匹配；不复用来源平台类目 ID。歧义或无匹配明确失败，不猜类目。
- 默认库存 999，来源重量优先、缺失默认 250g，包裹尺寸沿用既有默认；各 SKU 原价格通过现有汇率快照换算，不改来源数据。
- TikTok 创建固定 save_mode=AS_DRAFT，回读必须为 DRAFT；不自动上线。Shopee 仍沿用待上架逻辑。
- 原有幂等请求、批量重试、隔离失败商品和租户检查保留。

验证：前端 57 项、后端 37 项通过；新增双向批量测试、TikTok 官方配置路由测试及草稿回读验证；运行文件哈希核对完成。

边界：本轮未在 TikTok 店铺实际创建商品，不能宣称实店上传已测试通过。TikTok 仅开放现有 LOCAL 流程，CROSS_BORDER 仍明确阻止。不同语言类目、目标平台条件必填属性和视频迁移并未在此次自动补齐；由现有预检返回明确问题。本功能不包含从授权店铺 API 全量拉取在售目录，来源仍为采集器采集的商品。
