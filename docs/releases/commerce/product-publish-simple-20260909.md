# 一键上传表单简化（2026-09-09）

> 历史发布记录；镜像、测试与“当前/最新”均指记录当时。 当前入口见[业务说明](../../business/README.md)与[运维指南](../../guides/operations.md)。

用户确认：每 SKU 默认库存 999；重量优先沿用商品原值，没有时默认按 T 恤 250 克/件，不再要求补填。

单商品上传对话框现在读取目标 Shopee 店铺官方叶子类目和已启用物流渠道，用下拉替换日常 JSON 输入。仅完整类目路径唯一匹配时自动选择；单个物流渠道自动选择。成功创建上传任务后，将所选物流和同来源类目的目标类目映射保存在当前浏览器，按公司、平台、店铺区分。不同商品的重量、SKU 覆盖和价格不作为店铺默认值复用。高级字段默认折叠，校验失败时展开对应区域。

跨币种时显示目标币种统一 SKU 售价，避免将来源 PHP 数字当作 MYR。此表单简化未做汇率换算、自动猜测类目属性，也未自动执行真实发布。TikTok 继续使用既有字段，仓库/包裹尺寸可复用。

新增只读接口 GET /api/v1/shops/{id}/publish-options，复用现有公司归属和授权校验。接口只返回官方类目和物流业务响应，不暴露连接凭据。

验证：4 个前端测试通过（默认值、重量单位、配置隔离、异步店铺切换）；10 个后端测试通过（店铺授权、选项授权阻断、跨币种价格）；本地页面实测读取 2273 个官方叶子类目和 3 个已启用物流渠道。仅构造提交参数预览，未创建发布任务。后端与前端本地镜像已构建并部署。
