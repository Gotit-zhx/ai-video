# 批量上传只选择店铺（2026-09-09）

> 历史发布记录；镜像、测试与“当前/最新”均指记录当时。 当前入口见[业务说明](../../business/README.md)与[运维指南](../../guides/operations.md)。

已更新本地前端。批量弹窗只有目标 Shopee 店铺选择，商品清单可展开，删除库存、重量、物流、统一售价、类目手填和确认勾选。

批量与单传共用自动参数和原类目/物流匹配函数：库存 999；重量优先采集值，缺失 250 克；包裹默认 30×25×2 厘米；NoBrand；启用物流优先记忆值、否则第一个。各商品读取完整详情，保留每规格售价，提交 autoConvertPrice:true，由已有后端按采集币种和店铺地区锁定最新汇率。不传统一 publishPrice/publishCurrency，沿用后台 UNLIST、正式完整规格/沙箱前 50 规则。

逐件独立准备。失败项显示原因，其他商品继续；准备成功后在请求前持久化准确请求体/幂等键，重试跳过已接收商品。旧已发送任务保留准确原请求，未发送旧 PREPARED 记录重新使用自动参数。未保存编辑不覆盖，企业切换后停止旧任务写入。

验证：27 项针对性测试通过，涵盖自动默认值、混合币种/原售价、独立 SKU 规范化、失败隔离、幂等、企业隔离和静态文件打包。完整前端测试初跑 47 项中 46 项通过，剩余旧测试要求商品页保留 href="#shops" 入口，已在修改前部署快照中验证同样不满足（先前用户要求移除授权入口），不是本次回归。
