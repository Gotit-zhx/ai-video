## 已部署行为

独立印花提取、裂变在生图请求源头要求透明 PNG：网关发送 `background: transparent`、`outputFormat: png`，运行时向支持的 GPT Image 路由传递 `background` / `output_format`。商品底图与商品预览仍使用原照片输出设置。未知模型与 Grok 路由不发送不支持的参数，保留透明意图提示，并检查实际返回字节。

收到付费结果后先归档，再检查 PNG、alpha 与实际透明像素。真正可用的透明母版直接保留，不重复去白；非透明输出走本地去底与边缘去污染。PNG 扩展名、有 alpha 或提示词本身都不等于视觉质量合格。保持图案内白字、白色填充和插画人物服饰，不把插画内衣服识别成商品底图。

新建裂变自动准备每个商品／店铺的发布参数，在生图前验证并保存；提交时冻结参数，重试复用幂等身份。继续上传 TikTok 草稿 `AS_DRAFT`，没有改成在售。配置缺失的旧批次可自动补齐，无需再进行人工图片复核。提交图片包含各色正背面及 SKU 正背面组合图。

## 实际图像检查

图像证据保存在 `output/transparent-prints-20260915/`，需要将真实 alpha 检查与深色衣服上的视觉边缘效果分开判断。

查看 `matte-four-on-charcoal.png` 和 `black-results-preview.png`：三张原生透明裂变图没有明显整圈白底残留，文字与图案内浅色细节可见。V2 / G2 的非透明回退图，头发右侧和唱片／袖口之间仍有明显浅色区域，不能把本批结果描述为全部边缘完美解决。该缺陷已在平台草稿完成后发现；未覆盖已冻结发布素材或重复上传。

独立只读检查定位到 G2 / V2 头发／领口之间 `(540,230)–(660,340)` 的 498 个近白不透明像素，以及唱片下沿／袖口之间 `(701,403)–(812,505)` 的 2180 个；属封闭背景空隙残留。白袖口、狐嘴与耳毛属于应保留的设计元素。细节证据：`g2-v2-residual-white-gaps.png`。最小后续修正可绑定该源图 SHA 的背景种子，仅本地重抠和套版；本次未执行已上传草稿的图片替换。
