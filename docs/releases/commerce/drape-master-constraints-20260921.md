# 模板优先的搭放母图输入

> 历史发布记录；镜像、测试与“当前/最新”均指记录当时。 当前入口见[业务说明](../../business/README.md)与[运维指南](../../guides/operations.md)。

新母图参考顺序由“来源场景、模板定位、高清印花”改为“模板定位、来源场景、高清印花”。生成提示明确图1是唯一商品版型/布局依据，图2仅提供场景；胸花尺寸/侧别/位置不允许被高清素材画布影响。要求四周10%留白，完整领袖下摆，姿态冲突时减少姿态变化而非更换版型。

旧母图的 prompt 和引用顺序仍按旧格式验证、兼容恢复，不因代码升级重复付费或修改已冻结请求。已准备任务继续使用自己的已持久化 prompt，新建母图任务使用新规则。原有定位/轮廓保护检查仍保留。本次没有新增自动重生机制，也没有执行付费生图；生成约束不能保证模型每次都符合模板，原暂停任务仍需新的合格母图。

27项相关测试通过，包括旧母图兼容、未知结果不重复提交、预算耗尽不调用模型、参考绑定一致性。生产以精确依赖编译并核对修改前两个类 bytecode，部署 CommerceDrapeReuseWorkflow 和引用其常量的 CommerceBatchArtworkService，避免Java常量内联导致生成端仍使用旧提示。

编辑器核查：photo-print-preview.js 中图像/控制框/预览均使用 contain 后相同 frame，位置图按归一化 x/y/width/height 导出。未发现此次小胸花放大的证据来自编辑器坐标。截图是背面编辑，失败任务使用正面定位图。
