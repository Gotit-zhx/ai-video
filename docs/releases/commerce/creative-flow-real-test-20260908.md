## 图片质量复核

流程跑通不等于图片质量通过。暖色、冷色两个变体均成功套回粉色 T 恤，袖口旧图案已经移除；按用户后续确认，印花允许一定程度二创，复核结论更新如下：

1. 暖色变体和最终套版省略了原印花下方的 MiowTime / SukiSilk 文字，冷色版保留。用户确认印花可二创，因此文字增删、配色、表情、姿态和装饰变化不因偏离原印花而单独判为缺陷；若明确要求保留某元素，则按该要求检查。
2. 去印花底图将衣领标签的 150 改成了 160，两张套版继承了该变化。不能宣称版型和商品细节完全保真。
3. 套版 V1 / V2 的模板区域外像素变化比例为 4.494% / 3.728%，均标记 `OUTSIDE_CHANGE_REVIEW`，`productionReady=false`。这个比例是启发式像素差，不等于印花越界面积。
4. 当前彩色印花定位器不支持粉色底图，返回 `UNSUPPORTED_COLORED_BASE`，没有可靠的位置偏移结论。
5. 提取结果是白底候选；透明通道、文字准确性、印刷分辨率和生产文件验收未由这次流程证明。

## 实现与验证

- V75–V77：模型任务账本、仅创作模式、图片检查、不可变原图归档；本地数据库已升级。
- 自动流程：每轮最多提交一次模型调用，固定创作/模型配置；模型结果收到后先持久化再归档；未知提交结果不盲目重复生成；支持在途暂停和已归档结果的安全恢复。
- 来源域名在本机代理下解析到保留 IP，安全下载器拒绝直接读取。使用明确上传的原文件完成不可变归档，未放宽 SSRF 保护。

- 新批次创作配置支持在来源原图上拖动标记 1–8 处旧印花范围，范围随来源图片、版本一起固定；没有模板底图且没有清除范围时，在启动前拒绝，不锁死配置或占用模型调用。
- 去印花结果仅在选定清除范围内使用；套版结果仅在模板范围内使用。两者均在现有 1024×1024 等比留白画布上处理，范围外像素沿用对应基图。不能推断这是任意分辨率原文件的无损编辑。
