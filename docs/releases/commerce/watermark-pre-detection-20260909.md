## 后续前检规则

- 先检查原图。发现水印、不确定或检测失败时直接生图。
- 原图判为无水印时，先检查本地像素是否满足保守的简单近白背景条件：全图近白像素至少 50%，外圈 8% 范围近白像素至少 85%。近白定义为 RGB 最小值至少 235、通道差不超过 15。不满足条件时直接生图；这只是限制跳过生图的资格，不是断言图片一定有水印。
- 满足背景条件后，才用原图与一张暗部提亮、局部对比度增强的全画布副本做前置确认。增强前置确认最多等待 90 秒，失败或超时直接生图。
- 本地背景条件满足、两次均明确 `ABSENT`、置信度至少 `0.99`，且均无水印区域，才保留原图。冲突、不确定、格式错误和检测失败都不能走原图放行分支。
- 保存两次判定证据。增强副本只用于检测，生图仍使用原始归档，不增加生成后复核。
- 已保存的生成结果和已完成图片继续复用，不批量清空或重跑旧记录。

模型置信度不是经过校准的正确率。这项修改收紧了放行条件，不能把 `0.99` 描述为漏判率低于 1%。
