# 生成提示词修正：第一批（本地，未部署）

## 变更范围

1. 服装复核增加最多三个定向纠错目标：位置、母版可见证据、候选偏差、修正动作、必须保留的细节。下次整图重生成时使用这些目标，并继续复核；不是蒙版局部编辑。
2. 袖子纠错以原商品图为依据，明确区分画面侧与穿着者身体侧；保留原斜领、露肩范围、另一侧袖子、主印花与颜色。无法确认的隐藏结构不可编造，也不能把遮挡直接当成缺袖。
3. 新目标随重试状态持久化，兼容缺少该字段的旧复核结果。校验响应输出上限从 400 调至 2000 tokens，供结构化说明使用；未增加生成次数或复核次数。
4. 视频共用一套进入转场规则，不再因九宫格背景变化自行增加硬切。明确的拉远、全身、脚部展示等冲突构图在拼接时间轴前进行有限文本归一；有效的手部动作、转身、商品细节和否定禁令应保留。
5. 已知自动生成提示词升级为 V11.8 / DIRECT_DETAIL_V6 / PRODUCT_DETAIL_V7，沿用现有旧提示词迁移入口。普通自定义提示词不强制替换。
6. 按用户补充要求，加入共享背面图案来源规则：没有明确的背面参考就不生成背面印花/Logo/文字，不复制正面图案；独立背面图或正背多视角图有明确背面证据时保留真实设计。主图、分镜、视频与校验使用同一来源规则，不把 AI 候选图上的幻觉当作授权依据。

## 明确保留的限制

- 视频仍输入首帧、整张九宫格与商品母版，尚未改成独立分镜分段生成，也没有新增成片视觉质检；不能保证九宫格或多手不再出现。
- 本批未改变“最多三次重绘后选择最佳候选继续”和“校验不可用时回退”的现有策略，因此仍可能放行结构错误；硬性拦截应作为独立步骤验证，不能将本批描述为已解决放行问题。
- 文本归一只处理明确的构图表达，并非完整自然语言动作规划器。复杂脚本或手工提示仍需检查最终请求。
- 校验输出变长可能增加少量模型 token 费用和响应耗时。未发起真实付费生成来证明成片质量。

Node：`node --test pi-runtime/test/garment-topology-validation.test.js` 和 `node --check pi-runtime/src/server.js`。

测试覆盖校验 HTTP 响应到下一轮纠错提示、重试持久化、旧响应兼容、方向不确定与原斜领保护、连续/硬切、否定语义、商品款式词保留及旧自动提示词迁移；单元测试通过不等于真实生成质量通过。
