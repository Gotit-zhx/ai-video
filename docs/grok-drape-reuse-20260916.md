# 自然搭放母图复用

新建裂变与未冻结的创作配置支持 `GROK_DRAPE_REUSE_V1`。2026-09-17 修正新建入口：合格的小胸花模板默认选择自然搭放；已有配置、冻结批次和旧未确认请求保持原策略，详见 `grok-drape-default-fix-20260917.md`。

## 流程与调用边界

1. 使用已保存的四面照片模板与透明印花，先完成精确本地套版。
2. 取首款正面印花制作纯白定位图。Grok 参考来源商品的姿态和场景风格、定位图及同一印花，生成一次自然搭放母图。
3. 本地 SIFT 对照实际提交的定位图自动追踪胸前印花。结合离线 U2Net/GrabCut 分离衣服，对旧花局部重建平滑光照。
4. 固定母图、衣服遮罩和透视映射，按来源 SKU 的已验证布色换色、按各款透明素材换花；场景背景与搭放褶皱共用。
5. `DRAPED_FRONT` 为最终主图；`MOCKUP_FRONT` 和 `DRAPE_*` 为过程素材。背面和侧面仍由原有照片模板生成，发布附图保持同款同色关联。

“一次”指每批次、每来源商品的一次 Grok 搭放场景请求，与款式数量和颜色数量无关。透明印花提取/裂变单独按原规则计费；选择已有印花可复用这些素材。不同批次不会承诺永久免费复用场景。

母图已归档时恢复仅执行本地步骤。结果未知不会自动重复付费提交；本地校验失败保留母图和印花，无自动付费兜底。每个来源商品的场景调用计入批次上限。

## 当前支持范围

- 纯白服装照片模板，一处小面积正面胸花；背面、侧面位置可以保留。
- 胸花面积不超过画布的 6.5%，横向范围 20%–80%，纵向范围 12%–55%。最终母图还需通过特征追踪、透视、遮罩和胸部范围检查。
- 不将大花、跨袖口/领口、遮挡或强烈折叠强行套入已验证算法。
- 去旧花重建的是平滑光照，不能证明恢复未知的真实织纹；颜色来自商品图，不代表实体色号认证。
