## 本地接手验收

1. 安装 JDK 21、Maven 3.9.11、Python 3，以及用于本地 MySQL/Redis 的 Docker/Compose。
2. 在仓库根运行 `python3 scripts/dev.py init`，确认只在缺失时创建私有 `.env.development`，没有覆盖 `.env` 或其他环境文件。
3. 编辑本地密码/密钥并运行 `python3 scripts/dev.py run`。已有兼容依赖时可用 `--no-deps`。
4. 访问 `http://localhost:8080`，核对 UI、健康接口、登录和所开发模块。API 与 UI 同源。
5. 修改一个前端文件，确认无需 npm、gzip、镜像或 Java 重启即可从源码读取；可选自动刷新只在 dev 生效。
6. 修改一处可验证 Java 行为，确认 watcher 只编译到 `target/classes`，成功后触发 DevTools，并记录真实编译/重启时间。
7. 制造一次可恢复的编译错误，确认不会触发重启且上一可用上下文继续服务。
8. 按变更运行必要测试，记录通过、失败、跳过和未验证边界。

`pom.xml` 依赖变化会受控重启 app；Flyway、环境配置、工具链和 watcher 本身变化须显式维护及专项验证。

## 工程边界和已知缺口

- 默认源码入口只覆盖主 Java/Web 与本地 MySQL/Redis。Pi Runtime 可用 `npm --prefix services/pi-runtime run dev` 单独启动；招聘 Connector、ERP、下载、文档转换、水印和桌面端按各自 README 运行。
- 默认同源端口不等于生产 Nginx 的全部招聘/ERP 代理已在本地复现。
- 真实店铺、广告、模型和 OSS 能力需要各自授权与真实验收；主站健康不代表这些链路完成。
- 独立桌面安装包只在明确分发任务中构建，不是主应用内部开发前置条件。
- 历史发布 helpers 可能依赖 `/opt/heyi/releases/...` 已保留内容；它们不能改日期后直接重跑，也不是源码模式的默认入口。

## 必须继续保护的业务规则

- 企业、公司、店铺和角色权限不能只靠前端保证。
- 财务金额、日期、币种、成本、广告和结算口径不随运行方式改变。
- 缺失、待同步、未知与真实零值继续区分；不能把未同步数据说成完整。
- Flyway 只追加迁移，不修改已应用文件或校验和；数据库集成测试只连可销毁隔离库。
- 同步游标、检查点、租约、限流和结果未知记录继续保留；不能通过清队列或重发代替恢复。
- 凭据、密钥、Cookie、私有环境文件和完整业务导出不得进入 Git、公开文档或诊断输出。
