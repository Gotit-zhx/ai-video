# 模板与新建裂变的选择关系

2026-09-14。本轮将目标店铺从模板配置移到新建裂变；模板保留可复用的裂变数量与印花配置。

## 使用流程

1. 在「模板配置」调整裂变款式数量，并在下方保存商品与印花模板。印花模板保存原图、模型、图案位置及渲染关联。
2. 保存上方裂变配置模板时，关联下方当前已保存的印花模板固定版本。下方已有快照但还存在未保存修改、加载、生成或保存操作时，上方不能把旧快照当作最新内容保存。未关联印花模板的旧配置仍可读取。
3. 在「新建裂变」选择裂变配置模板、商品印花模板和本次目标店铺。前者提供裂变数量等规则，后者提供商品版型与印花位置；店铺独立多选，以本次选择为准。
4. 若裂变配置已关联印花模板，界面读取其固定版本作为默认值，也可以在创建前选择另一套已保存印花模板。历史版本不能被最新版本静默替代。
5. 创建后得到草稿批次及默认创作配置。开始前仍可调整来源原图、印花模板和每组裂变数量并保存；创建草稿本身不调用生图或发布商品。

模板页恢复了已保存模板选择和读取入口，采用紧凑黑白布局。目标店铺选择只存在于新建裂变流程。

## 数据与事务

- 新保存的工作流配置不绑定目标店铺：`shopIds: []`、`shopTargets: []`，`shopCount: 1` 仅作旧规划接口占位。实际创建批次不受旧模板的 `shopCount`、已选店铺列表或站点约束；目标平台、市场和币种由本次实际店铺解析。
- 工作流的 `configuration.printTemplateSnapshotId` 可关联一个固定 `PRINT_LAYOUT` 快照。新建请求中的 `printTemplateSnapshotId` 优先于工作流默认关联；后端验证其属于当前公司、模板类型正确且曲面素材完整。
- 新建流程的两个模板都有明确用途：工作流快照决定裂变规则，印花快照决定商品版型与模型位置。两者均保存具体版本，不以名称或“最新模板”替代。
- 批次、商品店铺条目及默认创作计划在同一事务中建立。默认原图优先选择来源商品主图；没有主图时使用第一张可用原图，没有原图则创建失败并回滚，不留下缺少创作计划的半成品批次。
- 默认创作计划使用 `artworkSource: SOURCE_PRODUCT`，从来源商品提取真实印花与画风。模板中的相同标记属于同组，多处位置共用同一张变体；不同标记组分别生成并全部替换。
- 每组裂变数量统一支持 1–20。新建默认取工作流中的裂变数量，开始执行前仍可修改。开始后固定计划版本与输入来源，不能通过修改模板改变已启动任务。

多平台、多国家店铺可独立选择；店铺必须属于当前公司且授权有效，原有刊登额度及测试/正式环境校验继续生效。移除旧模板店铺限制不会跳过这些实际店铺检查。

## 旧数据与异步保护

- 旧工作流仍可读取，其历史快照保留原始记录。重新保存时不再携带旧目标店铺；创建新批次时以本次实际目标为准。
- 已锁定的旧创作执行保持原有输入与规则，不静默转换为新流程。尚未启动的旧创作配置需要保存升级后才能显示为可启动。
- 批次创建继续使用幂等键和完整请求内容哈希。同一个键重试同一个请求返回原批次，不重复创建计划；相同键用于不同内容会被拒绝。改变模板或店铺后，前端重新建立请求状态。
- 工作流载入印花快照时按快照 ID 查询。加载期间暴露请求中的快照并标记未就绪，上方不能错误关联之前显示的快照。失败不会静默退回旧选择。
- 公司切换、后续模板选择或新编辑发生后，迟到的快照响应不能覆盖当前画布。没有保存过的新草稿也受保护；干净的初始编辑器及公司重置后仍可以正常加载模板。
- 载入未关联印花的旧工作流时，解除旧快照关联并保留当前画布，不把上一套印花模板自动绑定到新工作流。干净画布不会仅因解除关联而被错误标记为发生内容修改。
- 内层保存过程中若又选择另一工作流，原保存完成不能满足新关联。请求中的快照保持未就绪，需重新载入或显式选择印花模板。
