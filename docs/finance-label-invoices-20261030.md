# 月度贴单账单：异步导入与订单自动绑定

贴单金额改为读取仓库月度账单。原分组、国家固定单价不再参与计算；商品 SKU 成本、手动商品成本和财务结算日期口径保留。

## 支持的文件

- 订单费用明细：识别「参考号」「金额」「计费状态」「计费项类型」等列。参考号是平台订单号，金额固定为人民币。
- 仓库发票：读取「账单汇总」与「出库订单」，参考号绑定平台订单，操作费作为贴单金额。库内操作费不再次累计。
- `9月(2).xlsx` 的原始校验结果：280,630 行，人民币 504,467.50 元；707 行标记计费失败，2 行参考号为空。文件总额不等于当前结算期间已匹配订单金额。

## 处理流程

`QUEUED → PARSING → PREPARED → READY`

上传接口返回 HTTP 202。后台流式解析，500 行一批写入，按精确订单号匹配。文件完整性校验通过后才进入汇总。生成新的汇总版本并原子切换，失败或中断不会把半份文件计入财务统计。

页面显示排队、校验、已读取行数、自动匹配、完成、完成但有待处理项、失败及错误原因。失败可重试，处理中可离开页面，重新进入后继续查看。相同文件重复上传自动去重。

未匹配的来源长期保留。新店铺同步订单时，只唤醒相同订单号的待匹配行；不要求重传，不扫描全部历史 Excel。组织间数据隔离；多个店铺具有相同编号且缺乏唯一证据时保留待核对状态。

## 去重与金额

- 同一仓库 WMS 出库事件跨文件去重；一个订单多次真实出库可累加。
- 同一客户、仓库、订单、交易日的订单费用明细优先于旧发票来源。
- 正式成功费用优先于零金额占位；相同费用重复来源不重复扣款。
- 金额冲突、计费失败、缺订单号不会猜测或把未知费用当作已确认零成本。
- 财务总览、成本明细及导出读取同一生效汇总；按订单首次结算日期归属，刷单订单沿用已有经营汇总排除规则。
- 移除文件后在后台重新发布剩余来源；不删除商品成本、其他文件或手动成本。

## 资源与恢复

- 单文件 96 MB / 50 万行，解压总量 512 MB；2 个上传槽，待处理文件存储上限 512 MB。
- XML 流式读取；共享字符串和偏移存磁盘；禁用外部实体，拒绝有精度风险的长数字订单号。
- 单工作线程，数据库租约，多实例不会同时处理；批次事务有超时。
- 停机中断保留任务，重启重放未发布来源；暂时数据库错误最多自动重试 3 次。
- 文件完成后清理原始临时副本，失败文件保留 7 天供重试，崩溃遗留文件定期清理。
- 新迁移 V137 只创建账单队列、来源、状态、汇总和租约表。
