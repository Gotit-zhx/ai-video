# 知识库：文章附件与预览

知识库包含店铺运营、达人、短视频、系统使用、常见问题五个栏目。同一企业的有效成员可以查看和编辑；管理员可以查看版本和文件操作记录。

新建文章保留标题、正文、标签，在保存按钮上方直接选择附件。选择阶段文件仅在当前浏览器排队，保存文章成功后才按文章 ID 上传。单个文件最大 50 MB。上传失败可以重试，沿用原上传请求标识，不重复创建文章。关闭未保存的编辑窗口会丢弃所选文件；切换界面语言会保留表单和选中的附件。

原附件存储在 Dayan OSS。图片显示缩略图，点击可放大；PDF 可内嵌阅读；PPT/PPTX 首次预览由内部 LibreOffice 服务转成 PDF。成功的转换结果存入 OSS，并以企业、原文件 SHA256、转换版本缓存；失败不缓存，允许重试。所有格式保留原件下载。附件预览和下载都校验当前企业、成员和附件有效状态。

转换服务部署方式见 [document-preview/README.md](../document-preview/README.md)，可选 Compose 配置见 [compose.document-preview.yaml](../compose.document-preview.yaml)。服务没有公开端口，仅与应用共享内部网络，使用单独令牌、非 root、只读文件系统、临时目录和资源限制；不把企业文档送到外部在线 Office 查看器。应用主页面 CSP 必须包含 `frame-src 'self' blob:`，供鉴权后的 PDF blob 预览使用。

当前支持正文检索和受支持文件的文本提取保存；尚未启用向量检索或 RAG 问答。文章版本、原文件及提取文本保留，便于后续接入。
