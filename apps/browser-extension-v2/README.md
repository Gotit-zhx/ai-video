# 赫逸印花采集 v2.0

新版插件同时保存商品资料和原规格组合，以便套版后直接选店上架。已有图片记录可在原商品链接重新采集来补齐规格。

解压 ZIP，在 Chrome 扩展程序页面打开开发者模式，选择「加载已解压的扩展程序」，选中 `hoyee-print-collector-v2` 文件夹。Edge 也可通过扩展管理页面加载。v2.0 使用独立的目录和本地登录状态，可与「赫逸商品一键采集」同时安装。

已经安装旧版时，将新版解压到原插件目录，在扩展程序管理页重新加载，然后刷新已打开的商品页。

1. 登录 `hoyee.org.cn`，让插件连接同一企业。也可从插件工具栏登录。
2. 刷新 Shopee 或 TikTok Shop 商品详情页，点击「采集印花图 v2.0」。遇到平台验证时，完成验证后再采集。
3. 插件打开「商品运营 v2.0 → 采集链接」。选中商品图，确认提取印花，再选择采集模板套版。提取印花会调用图片模型，费用按平台配置计。

插件把图片地址和采集规格保存到独立的印花记录。

从项目根目录打包：

```sh
python3 apps/browser-extension-v2/scripts/package.py --output ./hoyee-print-collector-v2.zip
```

v2.0 复用同仓库的 Shopee、TikTok Shop 和登录适配器。打包脚本检查 Manifest 引用和所有 ZIP 条目。
