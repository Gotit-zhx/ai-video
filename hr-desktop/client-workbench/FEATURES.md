# 原助手功能保留核对

范围来自当前 `src/core.cjs`、`runtime/runner.py`、`runtime/passive_runtime.py`、
`runtime/active_sourcing.py` 和 `scripts/boss-agent/connector.py`。最终交付要求每行在
Windows 和 Mac 原客户端改造产物中成立，不能用离线夹具替代账号实测。

网站上的招聘需求池、储备人才、一二面审核、钉钉、入职跟进、BI 等是服务端/
前端业务，本次改造直接使用官网现有页面、布局、菜单和操作，未另建业务 UI；仍需在两端用真实授权账号联调，不能
仅凭入口存在判定功能保留。

r7 的隔离官网页面已连上本机服务，但该轮新登录页的二维码未在 35 秒内加载，UI 检查整体失败。随后正常用户配置启动的 r7 已目视确认二维码出现，当前需要扫码；不能认定升级后自动保留了 BOSS 登录。页面连接、原生登录和业务操作分别验收，不能以其中一项成功覆盖另一项失败。

“无痕”按日常使用连续性验收。修改版有独立标识和签名；不伪装原厂签名，
不保证平台无法检测，不移除真实鉴权、限额或风控停止。
