# Ai boss 安装与更新

## Windows

本次安装文件：`Ai-boss-Windows-Setup-6c09d85d5690.exe`。
安装包已经在 Windows 中完成首次安装、覆盖安装、卸载重装和资料保留检查。
真实招聘账号的全流程仍需在使用者电脑上验证。

1. 正常退出旧助手。关闭窗口可能只是隐藏，请使用应用的退出菜单。
2. 运行安装文件，按提示完成安装。本版安装到当前 Windows 用户，无需选择“所有用户”。
3. 从桌面或开始菜单打开 **Ai boss**。左侧切换 **BOSS** 和 **系统**。
4. 首次使用这套改造版时，在 BOSS 页面完成扫码，在系统页面登录有招聘权限的赫逸账号。
5. 确认顶部显示“网卡直连”“BOSS 已连接”，系统页面显示“招聘账号已连接”。

后续更新先正常退出，再覆盖安装。无需在 BOSS 或系统中点击账号退出。
运行中的更新或卸载会被拒绝；安装程序不会强制关闭正在使用的应用。
卸载保留账号资料和招聘记录。

安装位置为 `%LOCALAPPDATA%\Programs\AiBoss`。已有资料继续位于
`%LOCALAPPDATA%\HeyiBossWorkbench` 和 `%APPDATA%\heyi-recruiter`。
不要为了更新删除这些目录。单独安装本版不承诺自动导入其他 BOSS 应用的登录。

本次文件大小应为 **270,153,240 字节**，SHA-256 为：

```text
a982047b8993428d71e538810ad048b42f409401ebdb8dbfaf390edfabafc3d9
```

配套 `verification.json` 记录构建来源和检查结果。安装包仅供已授权的内部使用，
不发布到公开下载地址。

## Mac

应用位置：`~/Applications/Ai boss.app`。
正常退出旧版本，再打开新版本；两端账号资料沿用原路径。
本版使用黑底白色 Ai 图标，BOSS 与系统仍在同一个窗口内切换。

macOS 若出现钥匙串授权提示，请在系统窗口检查应用名称并自行处理。
新应用读取原加密资料前可能停在此步骤；不要通过删除资料来解决。
只有完成授权并实际显示两端已登录，才能确认此次更新保留了登录。

## 首次真实验收

安装检查使用隔离资料，不能代替下面这些实际结果。按照正常招聘工作验证，
不向无关候选人发送测试消息。
