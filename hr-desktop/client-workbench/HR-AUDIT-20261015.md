## 已修复的附件问题

固定 SDK 的 `save_resume()` 只返回随机保存路径、大小和格式，没有原文件名。
原生附件下载链路也丢弃了 `Content-Disposition`，因此仅修界面无法恢复名字。

本轮在原生下载、私有本机桥接、Python 传输和 SDK 适配中传递并解析这个
显示元数据，支持 UTF-8 `filename*`、普通 `filename` 和编码名称。
同时存在 ASCII 回退名称时，优先保留编码原名。

文件名只在原 SDK 完成附件内容验证和排他保存后作为 `originalFileName`
返回；不参与选择落盘路径。继续限制 20 MiB、校验真实格式、禁止覆盖。
仅允许传递有长度限制的附件名称头，不转发远端 Cookie、跳转或认证头。
下载仍是单次请求；不会因为本次修复增加自动重试。

Mac r11 已重新构建并通过签名校验。在原 Electron 22.3.24 / Node 16.17.1
中，使用真实本机 HTTP 响应验证了完整字节及响应文件名的传递，下载请求数为
1；打包 Python worker、SDK 源码保护、完整职位列表白名单、连接失败后的恢复、
